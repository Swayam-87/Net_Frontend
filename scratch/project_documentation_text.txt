1. Project Goals & Objectives  
Overview  
• The Student Project Management System is a role -based Web API application developed using 
ASP .NET Core technology. The system is designed to manage academic projects assigned to students 
under faculty supervision. 
• The application provides separate access and permissions for Admin, Faculty, and Students. The 
system focuses on project allocation, task management, score tracking, progress monitoring, and 
secure role-based authorization.  
• The system follows enterprise -level architecture practices while maintaining moderate project 
complexity suitable for academic implementation. 
Goals  
• Design a Normalized Database Structure:  
▪ Create efficient and normalized tables to manage Users, Roles, Permissions, Projects, Project 
Allocations, and Tasks. 
▪ Implement proper primary and foreign key relationships, including one-to-many and many-to-
many associations wherever required to maintain data integrity and consistency. 
• Implement CRUD & Authentication Functionality: 
▪ Develop Create, Read, Update, and Delete operations for all major entities such as Students, 
Faculty Members, Projects, Tasks, and Role Management.  
▪ Ensure secure user authentication and authorization using JWT tokens, along with smooth data 
management through role-based access control mechanisms. 
• Ensure Data Integrity and Validation: 
▪ Ensure that users can easily access project information, monitor progress, and perform their 
assigned responsibilities based on their roles. 
• Develop an Intuitive User Interface: 
▪ Provide a clean, user-friendly, and responsive frontend for efficient management of academic 
projects and related activities. 
• Encourage Good Software Development Practices: 
▪ Apply layered architecture principles, separation of concerns, and modular coding practices to 
improve maintainability and scalability. 
▪ Utilize design patterns, DTOs, dependency injection, and proper exception handling to develop 
a robust and enterprise-ready application. 
• Facilitate Effective Project Monitoring and Evaluation: 
▪ Enable faculty members to assign tasks, track student performance, and provide remarks and 
evaluations throughout the project lifecycle. 
▪ Automatically calculate project progress and score statistics to support informed academic 
decision-making.

Objectives  
• Student Management: 
▪ Enable administrators to create, view, update, and manage student profiles, including personal 
information, contact details, academic information, and project assignments. 
▪ Allow students to update their own profile information and view project -related details 
assigned to them. 
• Faculty Management: 
▪ Provide functionality to create and maintain faculty profiles, including departmental 
information, contact details, and areas of expertise. 
▪ Allow faculty members to supervise allocated projects and monitor the progress of assigned 
students. 
• Role and Permission Management: 
▪ Enable administrators to define and manage user roles such as Admin, Faculty, and Student. 
▪ Implement role-based permissions to ensure that users can access only the functionalities 
relevant to their responsibilities. 
• Project Management: 
▪ Facilitate the creation, modification, viewing, and deletion of academic projects, including 
project titles, descriptions, timelines, and status information. 
▪ Allow faculty members to initiate and manage projects under their supervision while 
maintaining project lifecycle records. 
• Project Allocation Management: 
▪ Enable administrators to allocate projects to students and assign faculty supervisors for 
effective project guidance. 
▪ Maintain allocation records to ensure proper tracking of project ownership and faculty 
responsibilities. 
• Task Management: 
▪ Provide functionality to create, assign, update, and manage project tasks associated with 
individual projects. 
▪ Allow faculty members to define task priorities, deadlines, and expected outcomes for 
students. 
• Student Performance and Score Evaluation: 
▪ Facilitate the assignment of scores and remarks by faculty members based on the completion 
and quality of assigned tasks. 
▪ Maintain records of earned scores and evaluations to support academic assessment processes.  
• Progress Monitoring and Tracking: 
▪ Automatically calculate and display task-wise and project-wise progress based on predefined 
evaluation criteria. 
▪ Provide students and faculty members with real -time insights into project completion status 
and pending activities.
